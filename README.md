# Грузоперевозки — Дмитров, Москва и МО

Посадочные страницы под Яндекс Директ: квиз с расчётом цены на первом экране, мультилендинг под группы объявлений, цели Метрики, приём заявок. Плюс обоснование для заказчика и план рекламной кампании.

## Просмотр

`client.html` — предложение заказчику: УТП, почему сайт будет конвертировать, модель окупаемости, план теста, что подтвердить.
`index.html` — сайт. Работает локально, без установки.

Мультилендинг: добавьте `?utm_content=g07` (или `?g=g07`) — заголовок и квиз подстроятся под группу объявлений. Коды групп — в `site.json` → `variants` и в `keywords-and-ads.md`.

## Структура

| Файл | Что это |
|---|---|
| `src/template.html`, `src/styles.css`, `src/app.js` | Исходники страницы |
| `site.json` | Бренд, телефон, часы, мессенджеры, Метрика, адрес приёма заявок, машины, варианты заголовков |
| `pages.json` | 4 посадочные: title, H1, подзаголовок, набор машин, направление по умолчанию |
| `tariffs.json` | Тарифы калькулятора (демонстрационные) |
| `build.py` | Сборка → `index.html`, `gazel.html`, `gruzovye.html`, `dmitrov-moskva.html` |
| `client.html` | Предложение заказчику (правится вручную) |
| `keywords-and-ads.md` | План Директа: кампании, 14 групп, фразы, минус-слова, объявления, цели |
| `brief.txt`, `analysis.md`, `queries.txt` | Бриф, анализ конкурентов, исходный список фраз |
| `greeting.html` | Личная открытка постоянному клиенту (с параметрами) или конструктор ссылки для менеджера (без параметров). Собирается из `src/greeting.*` |
| `privacy.html` | Заглушка политики персональных данных — заменить перед запуском |

После правки исходников или настроек:

```sh
python3 build.py
```

Сгенерированные `*.html` в корне не правьте — сборка их перезапишет. Если в шаблоне остался незаполненный `{{PLACEHOLDER}}`, сборка упадёт с ошибкой.

## Интерактив и праздники

- Сцена на первом экране (`src/scene.js`): технический рисунок машины в масштабе. Меняется по выбору тоннажа в квизе: старая машина уезжает, новая заезжает, фон стоит. Едет при прокрутке, фон реагирует на мышь и наклон телефона (Android; на iPhone наклон требует системного запроса разрешения, поэтому не используется).
- Фон первого экрана — фото машин (`img/hero-*.webp`) с параллаксом: сдвиг от мыши, прокрутки и наклона телефона, медленное приближение, световые полосы. Для каждого из 6 классов своё фото (`img/hero-1_5-*.webp` … `hero-20-*.webp`), оно сменяется вместе с выбором тоннажа. Сейчас стоят временные фото CC0 из Wikimedia Commons, источники — `img/CREDITS.txt`. Перед запуском заменить фотографиями машин заказчика.
- Праздники — `site.json` → `occasions`. Плашка на сайте появляется сама в окно дат; посмотреть заранее: `?occasion=avto`. Поле `greeting` и `wish` используются в открытке.

## Запуск в рекламу

В `site.json`:

- `phone`, `phoneTel`, `hours`, `telegram`, `max` — реальные контакты;
- `leadEndpoint` — URL, принимающий POST с JSON заявки (телефон, ответы квиза, UTM). Пока пусто — формы в демо-режиме;
- `metrikaId` — номер счётчика; цели отправляются автоматически (список — в `keywords-and-ads.md`, раздел 6);
- `demo: false` — убирает демо-плашку.

Также: политика обработки данных, реквизиты, подтверждённые тарифы и гарантии, коллтрекинг.
