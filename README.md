# Грузоперевозки — Дмитров, Москва и МО

Прототип для демонстрации заказчику: четыре посадочные страницы, предварительный калькулятор, быстрый звонок и обоснование проекта.

## Просмотр

Откройте `client.html` для презентации проекта или `index.html` для просмотра сайта. Все страницы работают локально без установки зависимостей.

Для просмотра через локальный сервер:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000/client.html.

## Состав

- `index.html`, `gazel.html`, `gruzovye.html`, `dmitrov-moskva.html` — страницы сайта.
- `client.html` — предложение заказчику и основания решений.
- `truck-scene.svg` — авторская изометрическая иллюстрация грузовика с анимированной линией маршрута; SVG лёгкий, работает без библиотек, анимация учитывает настройку reduced motion.
- `brief.txt` — вопросы перед запуском.
- `analysis.md`, `keywords-and-ads.md`, `queries.txt` — анализ и реклама.
- `base-template.html`, `calculator.html`, `calculator.js` — исходные части сайта.
- `tariffs.json` — предварительные тарифы и допущения калькулятора.

После изменения шаблона или тарифов:

```sh
python3 build.py
```

Сборка обновляет четыре страницы. `client.html` редактируется отдельно.

## Статус

Телефон демонстрационный, формы не отправляют заявки. Тарифы и зональные коэффициенты требуют согласования. API карт не используется. Секреты и ключи не нужны.

До рекламы: реальные контакты, получатель заявок, подтверждённые машины и тарифы, документы оператора сайта, аналитика и проверка доставки заявок.

## Публикация

Это статический сайт. Корень проекта можно разместить на статическом хостинге. Наличие репозитория само по себе не публикует сайт. Не размещайте секреты или персональные данные в HTML, JavaScript или `tariffs.json`.
